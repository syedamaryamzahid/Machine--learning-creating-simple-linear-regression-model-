# Simple Linear Regression: Salary Prediction

## Overview

This project demonstrates a simple linear regression workflow in Python for predicting employee salaries based on years of professional experience.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Methodology

1. Load salary and experience data from a CSV file.
2. Separate the independent and dependent variables.
3. Split the dataset into training (80%) and testing (20%) subsets.
4. Train a linear regression model using Scikit-learn.
5. Generate predictions on the test dataset.
6. Visualize the regression model and observed data.

## Dataset

The script expects a file named `Salary_Data.csv`, containing years of experience and corresponding salaries.

**Note:** The dataset is not currently included in this repository.

## Running the Project

Install the dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn
```

Place `Salary_Data.csv` in the working directory and run the Python script.
